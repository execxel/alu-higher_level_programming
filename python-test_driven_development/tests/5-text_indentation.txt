================================
How to Use 5-text_indentation.py
================================

This module defines a function ``text_indentation(text)``.

Usage
=====

Importing the function:
    >>> text_indentation = __import__('5-text_indentation').text_indentation

Text with '.', '?' and ':' delimiters and leading spaces:
    >>> text_indentation("Hello. How are you? Fine: thanks")
    Hello.
    <BLANKLINE>
    How are you?
    <BLANKLINE>
    Fine:
    <BLANKLINE>
    thanks

Text with leading spaces at the start:
    >>> text_indentation("   Start here.")
    Start here.
    <BLANKLINE>

Text with no special delimiters:
    >>> text_indentation("Just a normal line")
    Just a normal line

Empty string prints nothing:
    >>> text_indentation("")

Non-string input raises TypeError:
    >>> text_indentation(123)
    Traceback (most recent call last):
    TypeError: text must be a string

Missing argument raises TypeError:
    >>> text_indentation()
    Traceback (most recent call last):
    TypeError: text_indentation() missing 1 required positional argument: 'text'
