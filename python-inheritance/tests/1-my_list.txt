=======================
How to Use 1-my_list.py
=======================

This module defines a class ``MyList`` that inherits from ``list``.

Instantiation
=============

``MyList`` can be instantiated with no arguments, returning an empty list:

::

    >>> MyList = __import__('1-my_list').MyList
    >>> my_list = MyList()
    >>> type(my_list)
    <class '1-my_list.MyList'>
    >>> print(my_list)
    []

Or with a single iterable argument:

::

    >>> my_list = MyList([1, 2, 3])
    >>> print(my_list)
    [1, 2, 3]

Inheritance Check
=================

``MyList`` is a subclass of ``list``:

::

    >>> issubclass(MyList, list)
    True

Appending and Removing Elements
===============================

Standard list operations like ``append`` and ``remove`` work normally:

::

    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]

    >>> my_list.remove(4)
    >>> print(my_list)
    [1, 2, 3, 5]

``print_sorted`` Method
=======================

``print_sorted()`` prints the list in ascending order without modifying the original list:

::

    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]
    >>> print(my_list)
    [1, 4, 2, 3, 5]

Works with negative integers:

::

    >>> neg_list = MyList([-5, 10, -1, 0, 3])
    >>> neg_list.print_sorted()
    [-5, -1, 0, 3, 10]
    >>> print(neg_list)
    [-5, 10, -1, 0, 3]

Works with an already sorted list:

::

    >>> sorted_list = MyList([1, 2, 3])
    >>> sorted_list.print_sorted()
    [1, 2, 3]

Works with an empty list:

::

    >>> empty_list = MyList()
    >>> empty_list.print_sorted()
    []

``print_sorted()`` takes no arguments:

::

    >>> my_list.print_sorted(1)
    Traceback (most recent call last):
    TypeError: print_sorted() takes 1 positional argument but 2 were given
